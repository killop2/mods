# Flatout Car (NeoForge 1.21.1)

Машина (BMW M3 GTR E46 в стиле NFS: Most Wanted), которую можно водить. По клавише **G** или при сильном
ударе водитель вылетает через лобовое стекло вперёд и вверх и переходит в рэгдолл мода **Sable: Ragdolls**
(`RagdollAPI.launch`). Полёт считает физика Sable; этот мод задаёт только начальную скорость.
Если игрок уже в рэгдолле (например, его уронил Ragdoll Reactions), второй рэгдолл не запускается.
Длительность рэгдолла и выход из него (Shift) настраиваются в конфиге самого Sable: Ragdolls.

## Управление
- ПКМ по машине: сесть. Shift: выйти.
- W / S: газ / тормоз и задний ход. A / D: руль. **G**: вылет через лобовое стекло (меняется в настройках).
- Получить: креатив, вкладка «Инструменты», либо `/give @s flatoutcar:car_spawner`, либо `/summon flatoutcar:car`.
- Удар игрока по машине (не из неё): машина превращается в предмет.

## Вылет и столкновения
Скорость вылета (м/с) = база + коэффициент × скорость машины. На заднем ходу вылет назад.
Автовылет: при лобовом ударе о блок или сущность на скорости от `minSpeedKmh` (по умолчанию 45 км/ч,
максимум машины ~115 км/ч). Скольжение вдоль стены вылет не вызывает.

Параметры — серверный конфиг `saves/<мир>/serverconfig/flatoutcar-server.toml` (создаётся при первом заходе):

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `eject.forwardBase` | 14 | скорость вперёд при вылете с места |
| `eject.forwardPerCarSpeed` | 0.9 | + за каждый м/с скорости машины |
| `eject.upBase` | 18.4 | скорость вверх при вылете с места |
| `eject.upPerCarSpeed` | 0.42 | + за каждый м/с скорости машины |
| `eject.maxLaunchSpeed` | 60 | предел общей скорости |
| `crash.enabled` | true | автовылет при ударе |
| `crash.minSpeedKmh` | 45 | минимальная скорость удара |
| `mobs.enabled` | true | машина сбивает мобов/NPC/игроков |
| `mobs.minSpeedKmh` | 12 | минимальная скорость наезда |
| `mobs.launchMultiplier` | 1.0 | множитель скорости отлёта мобов |
| `mobs.killIfNoRagdoll` | true | убивать мобов, которым рэгдолл недоступен |
| `mobs.corpses` | true | сбитые мобы остаются лежать трупами и не встают |
| `mobs.corpseLifetimeSeconds` | 600 | сколько лежит труп (0 — навсегда) |
| `mobs.maxCorpses` | 40 | максимум трупов в измерении, старые исчезают первыми |

Для фиксированной скорости вылета поставьте оба коэффициента `...PerCarSpeed` в 0.
Пример: с места — 14 вперёд / 18.4 вверх; на полной скорости (32 м/с) — ~43 вперёд / ~32 вверх.
Высота полёта растёт как квадрат скорости вверх, поэтому для удвоения высоты скорость вверх умножена на √2.

## Наезд на мобов и NPC
Любой живой моб (ванильный, Custom NPCs, Easy NPC и др.) или другой игрок, попавший под корпус машины:
1. при `mobs.corpses = true` — становится трупом: рэгдолл Sable: Ragdolls без срока окончания. Полёт и падение
   считает физика Sable, моб под телом скрыт, без ИИ и звуков, не встаёт. Труп не умирает от ударов тела о землю
   (иначе Sable убрал бы тело); удар игрока по трупу его убирает. Срок жизни и лимит — в конфиге;
2. при `mobs.corpses = false` — рэгдолл через Ragdoll Reactions (встаёт, когда тело успокоится);
3. если рэгдолл невозможен (моб в чёрном списке Sable, моды не стоят) — отлетает по той же траектории и погибает.

Другие игроки становятся обычным рэгдоллом Sable (выход — Shift), трупами не остаются.

Команды (нужны права оператора / читы):
- `/flatoutcar revive` — поднять всех лежащих мобов и NPC в загруженной части измерения; `/flatoutcar revive 50` — в радиусе 50 блоков.
- `/flatoutcar clearcorpses` (или `... 50`) — убрать трупы.

Отлёт считается как неупругий удар: скорость моба = v·(1+e)·M/(M+m), M = 1300 кг, m — по объёму хитбокса
(игрок ~70 кг, курица ~12 кг, корова ~125 кг, железный голем ~580 кг), e = 0.15. Угол: моб выше капота
подбрасывается на 18–28°, низкий — толкается вперёд на 6–12°; скользящий удар отбрасывает вбок.
Машина теряет скорость v·(1+e)·m/(M+m). Мобы тяжелее 40% машины для водителя — стена (с автовылетом).
Пример: зомби при 60 км/ч летит ~18 м/с под ~23°.

## Звуки
`assets/flatoutcar/sounds.json`: мотор (тон и громкость растут со скоростью), удар, лёгкий толчок,
разбитое стекло при вылете. Сейчас это ванильные звуки Minecraft (своих файлов нет, мод лёгкий).
Чтобы поставить свои, положите `.ogg` в `assets/flatoutcar/sounds/` и замените в `sounds.json`
`{"name": "minecraft:...", "type": "event"}` на `"flatoutcar:имя_файла"`.

## Сборка
`build-d.cmd build` — JDK 21, кэши Gradle и temp на диске D. Готовый мод: `build/libs/flatoutcar-1.21.1-1.0.0.jar`.
Тестовый клиент: `build-d.cmd runClient`.

## Модель
Меш `assets/flatoutcar/meshes/car.json` + текстура `textures/entity/bmw_m3.png` (256×256), рисуется в
`client/CarRenderer.java` / `client/CarMesh.java`. Треугольники склеены в четырёхугольники (1698 граней).
Колёса крутятся по пройденному пути, передние колёса и руль поворачиваются при рулении.
Размер машины 5.9 × 2.8 × 1.74 блока (масштаб модели 1.25), хитбокс 2.6 × 1.7; перед бампером отдельно
проверяется зона, чтобы нос не въезжал в стены. Посадка водителя: `SEAT` в `FlatoutCarMod.java`.

### Замена модели
Конвертер Blockbench glTF → меш: `tools/fbxconv/GltfToMc.java`. Ожидает: Y вверх, перед машины в −Z,
группы `wheels_front`, `wheels_back`, `steering_wheel`. Берите текстуру, встроенную в `.gltf`.
```
D:\mods\tools\jdk-21.0.13+9\bin\java -cp <gson.jar> tools\fbxconv\GltfToMc.java model.gltf texture.png src\main\resources\assets\flatoutcar\meshes\car.json preview 1.25
```
Аргументы: glTF, текстура, выходной JSON, префикс PNG-превью, масштаб (1.0 = 1 пиксель Blockbench = 1/16 блока).
